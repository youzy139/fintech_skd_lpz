# MarketLens v0.4.4 测试版

日期：2026-11-14。本批在固定 `5174 / 18000` 合成预览完成编译与检查后开放网站验收，用户随后明确要求“继续开发”，按约定视为本批已初步验收，整理版本 `v0.4.4`、提交、标签与推送。该版本不是竞赛正式交付，远端 CI 必须按本批准确提交核验。

## 本批范围

- 单体与独立预警服务的背景证据按当前账号来源白名单逐来源读取，日历/公众号总数只聚合授权来源；全范围账号保留原查询路径。新增 `context.source_scope` 标识。
- 主后端→预警服务→数据服务继续传递并验证原用户 JWT，不以全范围服务身份替代调用者。单来源记录接口保留 `kind` 过滤，直接数据服务的越权明细继续以 404 隐藏。
- 受限资产账号回放 WebSocket 以 4403 拒绝；CSV 导出仍只使用已授权 API 数据，没有独立导出后门。
- Java 日窗口引入 Caffeine 3.2.0 热点去重缓存，默认每算子 10,000 个“日窗口 key + eventId”项。缓存未命中、驱逐或恢复后仍回源 `ValueState`；不替代 Checkpoint/Savepoint、Kafka 事务或 Python 金融模型。
- Maven CI 和 Flink Docker 构建执行 Java 测试，不再跳过。

## 验证

- 后端 **239 项通过，分支统计总体覆盖率 79.41%**；前端 **55 项通过**，生产构建和一条真实 Chrome E2E 主流程通过。
- Java **6 项测试通过**，完整 Shade JAR 构建通过。覆盖热点重复跳过状态读取、恢复后冷缓存回源、跨日隔离与冲突批次行为。
- 本机 Kafka/Flink 上完成四日合成数据本地/Kafka/Flink 对照，结果一致并生成 Savepoint；详见 [权限专项](../v0.4.4-service-scopes.md) 与 [Flink/Caffeine 专项](../v0.4.4-flink-caffeine.md)。
- 默认 + Flink Compose 配置和 8 处版本声明检查通过。四日对照通过后 Kafka 因 Windows 测试日志文件占用退出，不记为持续稳定性验收；测试进程已清理。

## 限制与待复验

真实 Redis/ClickHouse 权限矩阵、Docker 镜像重建和旧 Savepoint 恢复未执行；Docker API 当前不可用。“Flink 实时特征计算”仍由 Python 领域模型承担，赛题统一要求的职责差异需要竞赛方可追溯确认，不能视为已经关闭。大白名单背景查询未做性能验收，受限账号仍没有按范围重算的全市场模型或治理聚合。

固定验收预览继续使用前端 `5174`、后端 `18000`，不得新增端口。后续每批仍须先打开网站验收，用户“继续开发”后才升版提交。
