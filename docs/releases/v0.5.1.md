# MarketLens v0.5.1 测试版

日期：2026-11-15。本批在固定 `5174 / 18000` 合成预览完成检查后开放网站验收，用户明确要求“提交 明天再开发”，按约定视为本批已初步验收并授权提交推送，整理版本 `v0.5.1`、提交与标签。该版本是 WebSocket 容量与推送验证里程碑，不是竞赛正式交付。

## 本批范围

- 新增 `websocket_user_performance.py`：101 个独立 observer 用户及 JWT 会话，真实 Uvicorn、同一两日回放、独立订阅连接。
- 分别验证默认 100 与显式 128 连接上限，记录快照、逐日推送、拒绝码和错误率。
- 一名用户首日后断开，REST 补拉第二日并重连核对完成快照；慢消费者在 110 次状态更新后核对 100 条队列、最新状态和两日 REST 结果。
- 本地与 Compose 默认 `WS_MAX_CONNECTIONS_TOTAL` 从 100 调整为 **128**，环境变量仍可覆盖；每账号 3 条连接、租约续租/过期和最多 2 个运行中回放不变。

## 实测结论

- 上限 100 时，第 101 个连接以 `4429` 拒绝，不能算作超过 100 用户通过。
- 上限 128 时，101 个独立用户全部连接；200 个推送样本 p50 **14.509ms**、p95 **22.590ms**、p99 **23.592ms**、最大 **24.591ms**。
- 断线 REST 补拉和重连完成快照通过；慢消费者队列与 REST 两日结果补拉通过。
- 在单机、单进程、本地租约和合成数据条件下，本批暂定“独立用户 >100 且推送 p95 <100ms”检查通过。详细口径见 [WebSocket 记录](../v0.5.1-websocket-users.md)。

## 验证

- 后端 **249 项通过，分支统计总体覆盖率 79.63%**；前端 **56 项通过**，生产构建和一条真实 Chrome E2E 通过。
- 默认 + Flink Compose 配置、8 处版本声明和 `git diff --check` 通过。本批没有 Java 改动，未重新执行 Maven；既有 Java 6 项与打包结果保留。

## 限制与后续

本批不是 101 个同时运行的回放，也不是 Nginx、真实 Redis 租约、多实例、慢网络或公网验收。API 混合读取 p95 仍未通过，持续事件吞吐、端到端、特征/识别、Redis 热特征、页面与故障恢复目标继续阻塞 `v1.0.0`。

固定验收预览继续使用 `5174 / 18000`，不得新增端口。后续每批仍须先打开网站验收，用户“继续开发”后才升版提交。远端 CI 必须按本批准确提交核验。
