# MarketLens v0.6.10 发布说明

发布日期：2026-11-16。用户在本批固定网站复核后回复“继续开发”，按项目约定视为初步验收并授权升版、提交、推送和创建 `v0.6.10` 标签。本版仍是测试版，不是 `v1.0.0` 正式竞赛交付。准确提交 `eccf62a8f248a2f45465e888803d346bd3938dca` 的远端 backend、frontend、browser-e2e、flink、containers 五项任务均已核验成功，工作流运行 `43857217176`；旧提交成功记录未用于替代本次检查。

## 本版范围

- 新增 `web/scripts/page-performance.mjs` 和 `server/benchmarks/page_performance.py`，使用真实 Chrome 测量 9 个主要页面的新上下文冷加载、同上下文热 reload 和 Slow 4G 参考。
- 每页冷、热各 3 次，Slow 4G 各 1 次，共 63 个样本；保留逐次结果、页面可用条件、浏览器异常、主动中止、请求失败和 HTTP 错误。
- 新增 `/api/system/page-performance` 管理员只读接口；报告缺失返回 404，不可读或页面/接口/基准源码摘要过期返回 409，远程特征模式使用既有有界代理。
- 系统页新增冷/热 KPI、9 行逐页结果、Slow 4G 参考、计时边界和限制。报告位于 Git 忽略的 `server/data/benchmarks/page-performance.json`，API 和页面不执行压测。
- 本批是测量、报告与可观测性建设，**没有修改页面业务代码来加速加载，也不能把三轮测量器修正描述为页面性能提升**。

详细口径见 [真实 Chrome 页面加载性能专项](../v0.6.10-page-performance.md)。

## 真实测量

环境为 Windows 11、Python 3.12.15、真实 Chrome 157.0.8103.51、桌面 1440×1000、Vite 开发服务和单进程 FastAPI，输入为 3 个合成资产及临时管理员。

| 测量组 | 成功样本 | p50 | p95 | 最大值 | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| 新上下文冷加载 | 27/27 | 494.423ms | **957.171ms** | 961.747ms | 9 页各自 p95 均通过暂定 `<2s` |
| 同上下文热 reload | 27/27 | 115.147ms | **906.960ms** | 909.996ms | 9 页各自 p95 均通过暂定 `<2s` |
| Slow 4G 参考 | 9/9 | — | **25,266.879ms** | 25,266.879ms | 仅作参考，不宣称慢网络达标 |

最终 63/63 样本成功，非预期 HTTP 错误、脚本异常和其他请求失败均为 0；主动中止单独分类保留。每页冷、热仅 3 个样本，p95 是当前小样本的描述统计。

## 限制与后续

- 结果只覆盖桌面本机、合成数据、Vite 开发服务和单进程后端，不是 Nginx/生产静态构建、多进程、多节点、公网或全设备性能验收。
- Slow 4G 为 Chrome DevTools 模拟，单页仅 1 次；其数值不满足 2 秒，但该组仅作参考。移动设备、慢 CPU、更多浏览器和真实网络仍须复验。
- 研究案例、账号权限和审计记录未纳入本批，不声称全部 12 个路由均已测量。
- 独立用户 API、持续吞吐、端到端、Redis 多实例、资源使用和完整故障矩阵继续阻塞正式版。
- Java、Kafka/Flink 和容器应用实现未修改，本批未重新执行其专项；镜像标签更新不表示本地镜像已重建。
