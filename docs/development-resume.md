## 当前批次

- 规则仍为 `market_core` 的确定性函数。可配置两个历史分位、最少历史状态日和状态切换开关；完整配置生成 `rules-<hash>` 版本。
- 独立 `alert_rules.sqlite3` 保存版本与当前指针，只在首次无状态时初始化默认值；支持恢复历史版本，不删除版本。
- 本地单体与独立预警服务共用 `AlertRuleManager` 和纯规则；主入口代理规则正文与证据请求。ClickHouse 归档使用同一版本哈希。
- 保存/恢复会重建当前历史预警视图，不改写已保存回放结果。管理员操作记录 `rule_update`/`rule_activate` 审计；规则库与审计库不是原子事务。
- 每条预警携带 `rule_version`；证据包含完整当日/前一状态、实际值、阈值、历史日数、模型版本、训练截止日及当日状态 API 链接。
- 特征服务首页摘要检测共享活动版本变化并重建预警计数，避免首页与预警页不一致。
- 真实共享卷链路验收通过：默认版本列表 1000 条，0.95 分位版本 926 条，首页计数一致，证据一致，预警服务重启保留版本，回滚恢复原列表。
- 最终回归：后端 150 项、前端 23 项通过，Python 分支覆盖率 77.22%，前端生产构建通过。
