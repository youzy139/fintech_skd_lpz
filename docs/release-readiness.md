## 发布顺序

方案 PDF 可在 `web/` 执行 `npm run docs:submission` 重建；使用已安装的 Chrome（CI 使用 Playwright Chromium）。输出为 `server/data/release/MarketLens-product-technical-draft.pdf`，已核对 9 页全部有文字并视觉复核封面与数据模型页。产物保留在 Git 忽略目录，方案 Markdown 与导出脚本可审阅；当前不是完整送审终稿，ER/流程图还在独立 Markdown 中。

1. `v0.3.4` 当前本地基线已提交为 `c3b5e4c`，不重复提交、不移动既有标签。后续批次按用户确认规则推进。
2. `v0.3.5` 先完成状态身份与伪切换风险专项；`v0.4.0` 补数据/特征治理、热特征、数据范围权限和技术适配。
3. `v0.5.0` 形成性能、容量与恢复报告，`v0.6.0` 完成模型效果、预警回测与研究案例。任一强制项未达标，继续登记为正式版阻塞。
4. `v0.9.0` 在隔离环境完成干净源码/空卷、升级回退、故障和用户流程验收；经授权推送并核对候选提交 CI，形成完整 PDF/MP4 候选成品。
5. `v1.0.0` 全部门槛通过且获用户最终确认后，统一软件/镜像/文档版本，发布并核验远端与竞赛提交。计划目标为 2026-12-28，12-29～12-31 留作提交缓冲，不按日期自动发布。

- `v0.6.0` 增强研究可信度：状态稳定性、事件对照、误报率、缺失覆盖与模型卡；将“置信度”解释为距离权重，不宣传为预测正确率。
