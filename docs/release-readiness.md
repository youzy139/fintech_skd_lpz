# MarketLens 正式版准备与验收清单

核查日期：2026-11-11。发布版本：`v0.3.4` 测试版，包含 `2ec5f96` 及本批前端重构、缺陷修复和版本同步。用户已授权按此测试里程碑提交；具体范围见 [发布说明](releases/v0.3.4.md)。**未完成项继续保留，本次不构成 v1.0.0 发布。**

## 本批完成

- 全新研究型首页、统一浅色工作台、移动导航、权限导航、哈希路由及刷新/后退恢复。市场、状态、特征、预警、数据、回放与管理页面使用真实 API。

- 导入排除 NaN/正负无穷；缺失资产列入质量报告；空序列不再计入已加载资产。原始文件不变。
- 修复回放初始化异步返回覆盖用户输入日期的竞态：日历和已有会话就绪前禁用控制，失败可重试，卸载取消请求。增加延迟响应与失败重试回归。

- CI 前端任务增加官方 registry 高危/严重漏洞审计门槛；构建上下文排除浏览器报告与截图，避免测试产物进入镜像构建输入。远端 CI 须核对本次提交的实际运行结果，本地通过不代表远端通过。

## 发布顺序

方案 PDF 可在 `web/` 执行 `npm run docs:submission` 重建；使用已安装的 Chrome（CI 使用 Playwright Chromium）。输出为 `server/data/release/MarketLens-product-technical-draft.pdf`，已核对 9 页全部有文字并视觉复核封面与数据模型页。产物保留在 Git 忽略目录，方案 Markdown 与导出脚本可审阅；当前不是完整送审终稿，ER/流程图还在独立 Markdown 中。

1. 按用户最新授权将当前已实现成果提交为 v0.3.4 测试版，统一版本并记录 Git 标签；发布后核对远端提交和 CI。此授权不等同于正式版验收或补记用户页面体验。
2. 优先修性能与测量缺口：代理/鉴权/存储拆时、连接复用、缓存版本隔离、有界事件流水线；每轮同步验证三通道一致性。
3. 在隔离环境完成空卷启动、故障恢复、真实用户并发与权限验收；保留硬件、配置、提交号、原始结果。
4. 完成 [产品技术方案稿](submission/product-technical-design.md)、[数据模型与流程](data-model.md)、质量报告和演示视频，核实 PDF 页数、MP4 分辨率及长度。
5. 所有正式版门槛通过后，同步软件/镜像/文档版本，取得最终发布确认，再创建并推送 `v1.0.0`。v0.3.4 测试版发布不豁免这些条件。

## 后续产品方向

- 先增强研究可信度：状态稳定性、事件对照、误报率、缺失覆盖与模型卡；将“置信度”解释为距离权重，不宣传为预测正确率。
