## 页面与接口

在数据中心展开“来源文件与入库核对”，点击对应文件的“质量证据”。页面定位到文件面板，按需读取该文件的入库状态、逻辑记录数、日期范围、无日期记录数和比例，以及已登记字段的非空/空缺证据。文件仍按服务端分页加载；切换类型、搜索或翻页会关闭旧面板，切换文件和关闭面板会取消请求并忽略迟到响应。面板有独立失败重试。

新增只读接口 `GET /api/data/files/{source_id}/governance`，返回 `file-governance-v1`、目录版本和政策版本。主入口和独立数据服务沿用 `catalog` 功能域鉴权；无此功能域返回 403，不存在文件返回标准 404，目录代次变化或远程服务故障返回通用 503 与 `Retry-After: 5`，不暴露内部地址。

SQLite 与 ClickHouse 读取同一权威目录中的文件、日期和字段预聚合，字段最多查询 101 项以判断截断，只展示前 100 项。ClickHouse 只访问当前发布的 active 视图；请求生成前后核对目录版本。缓存包装直接委派，不新增质量缓存或事实源。远程客户端保留鉴权、请求 ID 和有界超时，仅本接口将上游 404 映射为不存在。

## 统计口径

- 空缺数为文件逻辑记录数减字段非空数，包含空字符串、null 和未出现字段。空白字符串、数值零和未验证的语义值沿用原解析器口径，不擅自改写。
- 多 Sheet 按整个文件合并，空缺比例不能解释成逐 Sheet 或必填字段完整率。历史统计可能未登记全空字段，字段目录不能当作完整源 schema。
- “统计范围核对”仅检查记录数非负、日期计数与已读取字段计数是否在记录总数范围内；不独立扫描和核对实际原始记录总数。未完成导入或统计不一致时不生成比例/字段空缺数；空文件比例为 null。
- 无日期表示当前解析结果缺少事件日期，不等于全部时间异常。文件级导入错误不是无效记录数。重复和语义异常仍为 null，不输出质量分数。
- 不扫描大型新闻原文件，不执行归档/删除/重算，不改变模型、预警或回放输入。
