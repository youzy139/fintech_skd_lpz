# MarketLens v0.6.11 发布说明

发布日期：2026-11-16。用户在本批固定网站复核后回复“继续开发”，按项目约定视为初步验收并授权升版、提交、推送和创建 `v0.6.11` 标签。本版仍是测试版，不是 `v1.0.0` 正式竞赛交付。本版远端 backend、frontend、browser-e2e、flink、containers 五项任务须按准确提交的实际运行记录核验，不使用 v0.6.10 的成功记录替代。

## 本版范围

- 市场总览新增资产观察列表、仅看收藏和显式“保存工作区”，保存搜索、类别、收藏过滤、选中资产和 60/250/500 日走势范围。
- 新增 `GET/PUT /api/research/workspace`，按当前用户名恢复和保存一份工作区；本地未启用认证时使用 `local-dev`。
- 身份 SQLite 新增 `research_workspaces` 表，保存偏好 JSON、修订号和更新时间；不新增行情、模型或回放事实源。
- 观察者可保存本人工作区，服务身份和仅有 catalog 权限的账号被拒绝；保存和读取均应用当前资产目录及白名单，权限收紧后裁剪旧收藏。
- 远程特征模式复用既有有界代理。保存失败保留未保存修改并可重试，不对搜索键入自动写入。
- Playwright 前端改为直接 Vite Node 入口、显式站点根目录和 `strictPort`，避免 npm 子进程退出导致固定端口拒绝连接。

详细口径见 [账号级研究工作区专项](../v0.6.11-research-workspace.md)。

## 本地验证

- 后端 **302 项通过**，分支统计总体覆盖率 **80.81%**，高于 30% 最低门槛。
- 前端 **71 项通过**，TypeScript/Vite 生产构建通过。
- 固定 `5174/18000` 的扩展真实 Chrome E2E 第二轮完整通过，覆盖“收藏 → 过滤 → 60 日 → 保存 → 刷新恢复”及原有市场、评估、预警、系统、权限和真实两日回放流程。
- 首轮 E2E 因 Vite 进程退出、管理员初始化请求 `Failed to fetch` 而失败，未进入本批功能步骤；修正启动方式后完整重跑，没有删除失败记录或放宽业务断言。
- 真实只读行情预览中保存中证500并在刷新后恢复，随后恢复原工作区内容；1440×1000 桌面和 390×844 移动 Chrome 已逐张复核，无页面脚本异常或根页面横向溢出。
- 八处版本声明同步为 `0.6.11`，锁文件只修改根包两处版本；提交前执行版本一致性和 `npm ci` 干跑校验。

## 限制与后续

- 每账号一份当前工作区，多标签页以最后一次成功保存为准；命名筛选集合、冲突合并和可分享研究链接未包含在本版。
- 偏好存储为 SQLite 身份库，不是 MySQL 元数据。真实 Compose、多进程、多节点和远程部署未在本批复验。
- 真实手动预览未启用认证；跨账号和资产权限由临时身份库自动化验证，不声称已用多个真实账号手动验收。
- 独立用户 API、持续吞吐、端到端、Redis 多实例、资源与故障矩阵、真实金融事件标注和 episode 回测继续阻塞正式版。
- Java、Kafka/Flink 和容器应用实现未修改，本批未重新执行其专项；镜像标签更新不表示本地镜像已重建。
