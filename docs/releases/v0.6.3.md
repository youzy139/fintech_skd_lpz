# MarketLens v0.6.3 测试版

日期：2026-11-15。本批可复核研究案例在固定 `5174 / 18000` 合成预览完成检查并开放网站验收，用户明确“继续开发”，按约定视为本批已初步验收并授权提交推送，整理版本 `v0.6.3`、提交与标签。该版本是研究流程里程碑，不是金融事件效果或竞赛正式交付。

## 本批范围

- 新增 `research-case-v1`：优先选择当前历史视图最近一次 `REGIME_CHANGE`，没有状态切换时才回退到其他最新预警；不使用 LLM 选择事件或生成标签。
- 新增只读 `GET /api/research/cases/latest`，复用同一统计证据和前一状态日背景；全资产范围账号可读，来源白名单继续生效。
- 新增 `#/case`：前后状态、六项特征差值、模型/规则版本、当时可见背景、覆盖提示和结论边界。
- 新增 `#/replay?start=...&end=...&mode=local` 深链。链接与已有会话不同则保留旧会话、显示新的输入，不自动创建或启动回放。
- 新增 `server/benchmarks/research_case_audit.py`，只读真实行情生成案例并实际运行对应本地逐日回放，严格核对末日状态。

## 真实案例与边界

真实案例为 **2026-01-31**：`震荡平衡 · C1 → 下跌承压 · C0`，模型 `walk-forward-aligned-v1-20251224`，规则 `rules-7aaaeab82c7ce2a5`。市场收益、波动率、动量、相关性、趋势和有效收益资产均保留前后对照。

同日有效收益资产从 **31 个降为 1 个**，所以状态比较同时受样本覆盖剧变影响，不能直接解释为全市场金融事件。真实本地回放处理 2026-01-30～31 两日，输入分别为 39 条和 1 条，末日状态与完整 walk-forward 案例严格一致。

计算一致只证明研究链路可复核，不证明金融事件、因果、预测准确率或投资效果。离线脚本不加载目录背景，页面 API 仍按前一状态日和账号来源范围加载。详见 [研究案例专项](../v0.6.3-research-case.md)。
