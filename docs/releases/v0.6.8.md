# MarketLens v0.6.8 测试版

日期：2026-11-16。本批独立用户 API 性能报告与认证读取优化已在固定 `5174 / 18000` 真实只读行情预览完成检查并开放网站验收，用户明确“好的，继续开发”，按约定视为本批已初步验收并授权提交推送，整理版本 `v0.6.8`、提交与标签。本文件随发布提交进入仓库；准确提交的远端 CI 须在推送后单独核验。本版不是 API 性能达标版本，也不是竞赛正式交付。

## 本批范围

- 新增 `independent-user-api-performance-v1` 只读报告及 `GET /api/system/api-performance`，系统页不执行压测。
- 展示每次新建连接和每用户长连接的请求成功数、p50/p95/p99、最大值、吞吐、分场景结果及逐轮冷/热结果。
- 新增 `api-performance-baseline-comparison-v1`，只有全部请求成功且负载、环境、连接模式和样本数一致的报告才能比较。
- 报告绑定 12 个认证、治理、入口、业务路由和目录运行源码 SHA-256；缺失返回 404，过期返回 409，管理员权限沿用 `/api/system/`。
- 认证用户/会话合并为一次 SQLite JOIN，不读取密码字段，不改变 JWT、权限、退出、停用或用户版本撤销语义。
- 默认工作线程在 readiness 之前预热；客户端冷轮次仍全部计入整体 p95。

## 最终同口径结果

101 个独立合成用户、每种连接模式 5 轮、各 505 请求，均使用隔离数据和身份库：

| 连接模式 | 此前 p95 | 本次 p95 | 变化 | 成功/请求 |
| --- | ---: | ---: | ---: | ---: |
| 每次新建连接 | 433.145ms | **423.317ms** | 减少 9.828ms（2.269%） | 505/505 |
| 每用户长连接 | 398.439ms | **338.736ms** | 减少 59.703ms（14.984%） | 505/505 |

两种模式仍未通过暂定 `<50ms`。最终长连接首轮 p95 457.625ms，后续四轮为 127.622、145.529、152.291、118.882ms，全部计入整体结果。目录汇总和目录记录服务端 p95 仍分别为 77.565ms、120.007ms。

中间单查询和预热诊断测量全部保留在[专项记录](../v0.6.8-independent-api-performance.md)，没有挑选中间最低值作为最终结果；先后测量不能证明单项改动的因果贡献。

## 验证

- 后端 **280 项通过，分支统计总体覆盖率 80.42%**。
- 前端 **65 项通过**，TypeScript/Vite 生产构建通过。
- 固定端口真实 Chrome E2E 通过，覆盖报告缺失 404 和既有完整业务流程；合成 E2E 不伪造 101 用户报告。
- 固定真实只读预览已核对实际 API 200、报告版本、前后对照及未通过状态；桌面和移动截图已复核，移动根页面无横向溢出。
- 本批未执行真实 Redis/ClickHouse、多进程、跨实例或公网基准；Docker API 当前不可用，未做容器复验。Java、Kafka/Flink 实现未修改，未重新执行其专项。
- 8 处版本声明、锁文件干跑与 `git diff --check` 在提交前复核；远端 CI 以本版准确提交的实际运行结果为准。

## 限制与后续

API 暂定 50ms 目标继续阻塞正式版，后续优先处理目录查询和冷轮次性能。混合读写、持续吞吐、端到端、Redis 热特征、页面、资源和故障性能未关闭；真实事件标注、独立复核与 episode 误报回测仍未完成。

固定验收预览继续使用 `5174 / 18000`，不得新增端口。后续每批仍须先打开网站验收，用户“继续开发”后才升版提交。
