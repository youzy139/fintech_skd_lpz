# MarketLens v0.6.9 发布说明

发布日期：2026-11-16。用户在本批固定网站复核后回复“继续开发”，按项目约定视为初步验收并授权升版、提交、推送和创建 `v0.6.9` 标签。本版仍是测试版，不是 `v1.0.0` 正式竞赛交付。准确提交的远端 backend、frontend、browser-e2e、flink、containers 状态须在推送后单独核验；旧提交成功记录不能替代。

## 本版范围

- 新增可重跑的 `server/benchmarks/feature_cache_performance.py`，以真实本机 Redis、独立合成三资产、临时身份库和随机命名空间测量生产热特征路径。
- 新增 `/api/system/feature-cache-performance` 管理员只读接口；报告缺失返回 404，不可读或源码/基准脚本摘要过期返回 409，远程特征模式使用既有有界代理。
- 系统页新增 Redis 热特征 KPI、延迟表、逐轮结果、行为检查和限制说明；完整 HTTP 与未命中回填只作参考，不与主口径混用。
- 报告绑定七个生产源码文件及基准脚本 SHA-256，位于 Git 忽略的 `server/data/benchmarks/feature-cache-performance.json`。API 和页面不执行压测，不新增模型或缓存事实源。

详细口径见 [真实 Redis 热特征性能专项](../v0.6.9-redis-feature-performance.md)。

## 真实测量

环境为 Windows 11、Python 3.12.15、24 逻辑 CPU、独立 Redis 8.0.5 Alpine 容器，standalone，使用 tmpfs 且不挂正式卷；输入为 3 个合成资产、1,000 个工作日。

| 测量路径 | 样本数 | p50 | p95 | p99 | 最大值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Redis 有效命中·生产服务主口径 | 1,000 | 0.530ms | **0.795ms** | 1.014ms | 3.047ms |
| Redis 未命中与权威快照回填 | 20 | 1.047ms | 1.244ms | 1.532ms | 1.532ms |
| 完整 HTTP 单长连接·参考 | 200 | 2.330ms | 3.292ms | 4.048ms | 15.113ms |

按暂定 p95 口径，生产服务有效命中在本测量范围通过 `<10ms`。HTTP 的 200 次请求均成功且返回值一致，但顺序单连接不能替代 101 独立用户混合负载。

真实 Redis 写入/命中、权威结果一致、独立服务对象共享命中、未命中回填、TTL、损坏修复、拒绝连接回退、熔断打开/恢复、受限账号 403 和权限先于缓存读取共 11 项检查全部通过。

- 真实只读行情预览 readiness 与热特征报告 API 返回 200；1440×1000 桌面和 390×844 移动 Chrome 已逐张复核，无页面脚本异常或根页面横向溢出。
- 八处版本声明同步为 `0.6.9`，锁文件只修改根包两处版本；提交前执行版本一致性和 `npm ci` 干跑校验。

## 限制与后续

- 结果只覆盖同机单 Redis、合成数据和两个独立 Python 服务对象，不是多进程、多节点、Nginx、公网或正式容量验收。
- 故障使用拒绝连接端点注入，未停止 Redis 进程，未测持久化、复制和节点故障；权限使用临时合成账号。
- 真实赛题数据、多进程/节点、完整故障矩阵和资源使用仍须复验。独立用户 API、持续吞吐、端到端、页面及其他性能缺口继续阻塞正式版。
- 本批 `market.py` 摘要变化使旧独立用户 API 报告在真实预览中按设计过期，未继续把旧测量作为当前源码结果。
- Java、Kafka/Flink 和容器应用实现未修改，本批未重新执行其专项；镜像标签更新不表示本地镜像已重建。
