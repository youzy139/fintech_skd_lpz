# MarketLens v0.6.7 测试版

日期：2026-11-15。本批同口径性能前后对照已在固定 `5174 / 18000` 真实只读行情预览完成检查并开放网站验收，用户明确“继续开发”，按约定视为本批已初步验收并授权提交推送，整理版本 `v0.6.7`、提交与标签。本文件随发布提交进入仓库；准确提交的远端 CI 须在推送后单独核验，不能沿用前一版本结果。本版是性能证据展示里程碑，不是全部性能达标或竞赛正式交付。

## 本批范围

- 新增 `performance-baseline-comparison-v1`，在既有单日计算性能报告中增加可选基线对照，系统页不执行基准。
- 特征单日、状态非重训和状态重训分别展示此前 p95、本次 p95、变化毫秒数、变化百分比和样本数。
- 延迟下降写“减少”，上升写“增加”，无样本显示缺失；不把任何变化统一包装成改善。
- 展示基线提交号、生成时间及双方运行源码 SHA-256，保留代码血缘。旧报告没有对照字段时保持兼容。
- 合成 E2E 使用同代码的两组测量只验证页面结构，不宣称优化效果；真实预览使用本机只读行情，不读取真实账号。

## 可比性约束

只有两份完整、回放结果一致且目标可判定的报告才能比较，并要求事件起止日、每轮事件日数、轮次、资产数、数据口径、延迟统计、测量边界、温度边界、操作系统、Python 版本、逻辑 CPU 数及各阶段样本数相同。任一条件不符即拒绝比较，不把不同负载拼成提升率。

对照是同机同区间先后观测，不是随机对照实验、全历史结论或生产 SLA。
