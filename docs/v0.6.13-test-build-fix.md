## 原因与修复

在修复 E2E 按钮名称歧义时，给 `web/src/MarketOverview.test.tsx` 的 Testing Library `getByRole` 也加入了 Playwright 风格的 `exact: true`。Testing Library 当前类型不支持该选项，干净 TypeScript 构建在五处调用报 `TS2769`。

修复仅移除这些测试调用中的 `exact` 属性。Playwright E2E 中的 `exact: true` 保留，因为它受支持且用于区分“保存工作区”和“恢复已保存工作区”。不改变运行时代码、链接行为、API、模型、规则或回放结果。
