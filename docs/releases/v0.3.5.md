# MarketLens v0.3.5 测试版

日期：2026-11-11。用户已明确将此前“继续开发”认定为前批成果的初步验收，授权整理、提交与推送本版。本版是状态身份正确性补丁，不代表竞赛正式交付。`v0.4.0` 特征契约开发保留在后续工作区，不包含在本标签中；既有 `v0.3.4` 标签不移动。

## 范围与兼容

- 修正相同中心在重训时因局部簇编号置换产生的额外状态切换。通过原始特征单位、前次训练尺度与全局一对一匹配继承身份，同名不同中心仍保留独立身份。
- 状态新增 `regime_id`、`regime_identity`；`cluster` 保留局部诊断含义，新模型版本为 `walk-forward-aligned-v1-训练截止日`。训练仍排除当日，不改变特征、聚类预测、贡献或置信度算法。
- 新会话持久化身份算法；旧快照缺字段时采用 `local-cluster-v1`。旧逐日结果不改写，恢复/重开继续采用原身份算法。其他参数仍依赖原配置，完整参数血缘属于后续版本。
- 固定 SciPy 直接依赖，补齐编号排列、真实切换、尺度变化、全局匹配、旧算法输出和恢复行为测试；提供只读历史核查与三通道对照工具、结果摘要和评估协议草案。

## 验证与限制

2026-11-11 对隔离发布候选重新执行：后端 177 项、前端 39 项、TypeScript/Vite 生产构建及 Chrome E2E 全部通过，分支统计总体覆盖率 77.44%。最大图表共享包 480.07 kB；Chrome 使用独立合成数据，不能作为正式性能证明。核心源码摘要与历史审计一致，差异空白检查通过。历史实机证据：四日跨重训 local/Kafka/Flink 状态与预警一致，Flink Savepoint 生成；该记录不是本次重新执行，也不是持续吞吐或恢复达标证明。

真实行情只读审计覆盖 39 资产、314,318 条有效行情、3,340 状态日和 53 个后续重训边界。切换预警 525→500，减少 27、增加 2，均在重训日；两类分位数预警不变。差异不能称为金融事件确认的误报减少。中心强制一对一匹配仍不能解决严重漂移、分裂或合并，跨独立训练编号不可直接比较。详见 [专项报告](../v0.3.5-regime-identity.md) 和 [可审阅结果](../v0.3.5-regime-identity-results.json)。

镜像重建先遇 PyPI DNS/下载停滞、后遇 Docker Engine 未启动，尚未通过；本版镜像标签声明已同步，但没有据此声称新镜像已构建或部署。评估协议团队确认、人工事件标注、完整模型效果、正式性能、空卷 Compose、远端 CI 与竞赛 PDF/MP4 仍需补齐，见 [正式版准备清单](../release-readiness.md)。用户验收及 Git 标签不关闭这些缺口。
