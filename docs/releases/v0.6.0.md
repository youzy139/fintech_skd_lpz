# MarketLens v0.6.0 测试版

日期：2026-11-15。本批首批模型稳定性评估在固定 `5174 / 18000` 合成预览完成检查并开放网站验收，用户明确“验收通过 继续开发”，按约定视为本批已初步验收并授权提交推送，整理版本 `v0.6.0`、提交与标签。该版本是模型稳定性评估里程碑，不是竞赛正式交付，也不代表模型金融效果已达标。

## 本批范围

- 新增纯领域 `market_core.models.evaluation`：同一 Python walk-forward 模型运行训练窗口 `{504,756}` × 重训间隔 `{63,126}` × 随机种子 `{42,2026}` 的完整 8 组网格。
- 输出全部历史、开发、验证、操作留出四区间的 ARI、语义一致率、切换频率、持续期和重训边界指标；保留每区间 28 个两两比较及逐日最小结果。
- 新增只读 `GET /api/regimes/evaluation/stability`，由特征与状态服务拥有，主后端沿用代理。缺失返回 404，损坏或输入/特征/模型/评估版本过期返回 409，受限资产账号返回 403。
- 新增 `#/evaluation`：完整参数表、基准对照、两两 ARI 矩阵、区间切换、JSON 导出和血缘摘要。API 请求不触发训练，不修改当前模型、预警或回放。
- 新增 `server/benchmarks/regime_stability.py`，只读真实行情生成汇总与逐日 JSON，不加载运行数据库或身份库。

## 真实结果与边界

真实 39 个有效资产、314,318 条行情形成 3,844 个特征日，每组 3,340 个状态日。全历史两两 ARI 最小/中位/最大为 **0.084 / 0.284 / 0.993**，验证区间为 **0.417 / 0.566 / 0.991**。训练窗口和重训间隔变化可产生明显分区差异，不能宣称模型具有跨参数稳定性，也不能据此回头挑选“最佳”组合。

ARI 不是预测准确率，语义一致率不证明画像相同。全部历史曾用于工程验证，操作留出不宣称从未查看；协议仍为草案。真实事件标注、独立复核、预警 episode 匹配、误报报告、缺失覆盖和模型卡仍未完成。详细口径、单维对照和血缘见 [稳定性专项](../v0.6.0-regime-stability.md)。
