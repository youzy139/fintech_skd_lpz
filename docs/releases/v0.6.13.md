# MarketLens v0.6.13 发布说明

发布日期：2026-11-18。用户明确要求“继续开发”，按项目约定视为本批修复已获初步验收，并授权升版、提交、推送和创建 `v0.6.13` 标签。本版仍是测试版，不是 `v1.0.0` 正式竞赛交付；既有 `v0.6.12` 标签不移动。远端五项 CI 待准确提交推送后核验，不预先宣称通过。

## 本版范围

- 移除 `web/src/MarketOverview.test.tsx` 五处 Testing Library `getByRole` 调用中不受支持的 `exact: true`，修复干净 TypeScript 构建的 `TS2769` 错误。
- 保留 Playwright E2E 的 `exact: true`，继续区分“保存工作区”和“恢复已保存工作区”。
- 不改变运行时代码、研究链接行为、API、模型、确定性规则或回放结果。
- 八处版本声明同步为 `0.6.13`，锁文件只修改根包两处版本，Compose 镜像声明和 Flink 工件版本一并更新。

详细原因与验证见 [前端测试干净构建修复专项](../v0.6.13-test-build-fix.md)。

## 限制与后续

- 本批是测试构建修复，不新增业务功能，不构成金融效果、预测准确率或性能结论。

- API、持续吞吐、端到端性能、真实金融事件标注、episode 回测、空卷部署和正式竞赛材料等既有缺口不因本版关闭。
