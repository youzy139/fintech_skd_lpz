## 本版变化

- 特征定义/版本接口展示单位、窗口、最少样本、输入范围和算法版本；新回放固定计算参数及输入摘要，恢复时校验，旧回放结果保持原有语义。
- Redis 当前特征快照热读，键包含数据/特征/模型/输入版本、参数、日期、视图和权限范围；仅读已计算当前快照，历史回放读持久化结果。TTL、损坏、拒绝连接和熔断回到同一权威快照，系统监控来自实际特征服务。
- 数据中心按来源类型展示日期/字段证据、时间使用边界和人工保留政策；逐文件面板展示入库状态、日期覆盖与字段非空/空缺，支持独立重试、切换取消、移动布局和自动定位。重复/语义异常仍为未评估，不生成质量分数或执行归档/删除。
- 代码/API、前端包及页面、Compose 镜像声明、Flink 工件统一 `0.4.0`。后端版本集中在 `app.version`，页面取包版本；`python scripts/check_versions.py` 核对包/锁文件、后端、镜像与 Flink 声明，已加入 CI。

此前特征契约/Redis 提交 `70e64f7`、异步测试修复 `18d9c98` 与来源治理 `485e0b4` 纳入本版，既有标签不移动。逐文件代码和本次版本整理一起提交。
