# MarketLens v0.3.4 测试版

发布日期：2026-11-11。版本定位：可体验、可回归的开发里程碑。用户已授权以 v0.3.4 提交本批成果；这不表示 v1.0.0 竞赛验收完成，也不补记未经用户报告的页面体验结果。

## 版本范围

- 服务治理：独立数据、特征状态和历史预警服务；保留 Nginx + FastAPI 单入口与本地单体模式。JWT、角色/功能域权限、Redis 共享限流、连接租约、计算并发、审计归档与依赖监控已落地。
- 可复现分析：三种历史回放通道、持久化与断线补拉；可配置确定性规则及版本恢复；状态热力图、阈值证据和时间受限的经济日历/公众号背景。
- 前端重构：研究首页、浅色工作台、移动导航、权限导航、哈希路由、资产筛选、历史曲线、CSV 导出及错误重试。
- 缺陷修复：排除非有限行情值，准确列示缺失资产；避免回放初始化异步响应覆盖用户日期；图表响应容器尺寸变化并释放资源。
- 工程交付：持续测试/构建/浏览器流程、依赖审计、数据质量报告、ER/数据流图、9 页方案 PDF 草稿生成器与演示脚本。更新 ECharts、Vite、Vitest 锁定版本。

## 验证依据

完整功能回归：后端 162 项通过，启用分支统计的总体覆盖率 77.31%；前端 34 项通过；TypeScript、生产构建与 Chrome E2E 通过。官方 npm registry 审计为 0 个已知漏洞。Docker 镜像、Compose 和 Nginx 检查通过。同步 0.3.4 版本后，主 API/数据/预警服务共 25 项测试、前端生产构建及 Compose 配置再次通过，方案草稿已重建。远端 CI 结果需按本次提交实际运行状态核对，不以本地测试代替。

真实目录包含 1,046 个文件、1,556,492 条逻辑记录；39 个行情资产可用，缺失“全球高收益债”。本轮容器验证恢复既有数据卷，不属于干净环境或空卷验收。原始数据、身份库和运行卷未重建。

## 安装与升级

依照 [README](../../README.md) 和 [部署说明](../stage-e-deployment.md) 配置环境；代码、API、前端包、Compose 镜像与 Flink 工件版本统一为 0.3.4。前端在 `web/` 执行 `npm ci`、`npm test`、`npm run build`；后端按 README 执行完整 pytest。容器升级前备份私有配置、身份/规则/回放数据库及运行卷，再构建对应服务并检查 readiness。避免使用 `down -v`；既有账号与原始输入继续保留。

## 延后事项与正式版边界

- 并发与吞吐未达赛题目标：100 路请求 p95 为 1.84–2.33s，并非 100 个独立用户；两日回放约 5–9.5 条/秒，不代表持续事件流吞吐。
- 补充 101 个以上独立用户、连续事件流、热特征、重训与非重训的代表性基准，以及空卷启动和故障恢复复验。
- JWT 与功能域权限已实现；OAuth2/OIDC、行级权限尚未实现。当前使用 Python LRU + Redis，未引入 Java Caffeine，需核实竞赛接受度。
- 补模型效果、稳定性与误报报告；方案 PDF 仍缺团队信息和完整效果论证，ER/流程图待整合，1080p、5 分钟以内 MP4 尚未录制。
- 单节点依赖与历史回放不代表高可用或实时行情服务。LLM 不参与状态、预警等级或回放计算。

原 v0.3.4 任务书的未完成目标转入后续开发与 v1.0.0 验收，不删除、不视为通过。详见 [正式版准备清单](../release-readiness.md) 和 [性能报告](../v0.3.4-performance.md)。根目录既有 AGENTS.md 按用户要求保留原文，其旧版本状态以本发布记录和后续用户指令为准。
