# v0.6.0 开发专项：市场状态稳定性评估

核查日期：2026-11-15。本批已通过固定网站初步验收，用户明确“验收通过 继续开发”，据此发布为 `v0.6.0` 测试里程碑并整理提交、标签与推送。实现只新增只读评估、报告和展示，不改变当前模型、预警规则或已保存回放。

## 1. 范围与固定实验

赛题演示文稿第 14 页将“状态画像与解释质量、应用效果论证、稳定性与连续性”列入模型应用适配性评分。本批先完成无需金融事件标注即可复核的稳定性部分；事件命中、漏报、误报和提前量仍须团队按[评估协议](model-evaluation-protocol.md)提供真实标注与独立复核，不能由模型或 LLM 补造。

- 纯领域模块：`market_core.models.evaluation`，跨参数运行同一 Python walk-forward 模型，不读取 `server/` 或 `web/`。
- 固定网格：训练窗口 `{504, 756}` × 重训间隔 `{63, 126}` × 随机种子 `{42, 2026}`，共 **8 组**；固定 504 个预热特征日、3 簇、`centroid-alignment-v1`。当前基准 `w756-r63-s42` 必须包含在网格内。
- 区间：全部历史、2017～2021 开发、2022～2024 验证、2025～2026-04-30 操作留出。全部历史曾用于工程验证，操作留出不宣称从未查看过；协议仍为 `evaluation-v1-draft`，待团队复核。
- 指标：共同日期 ARI、语义标签一致率、每 100 状态日切换数、区间截断持续期、重训边界切换占比与边界切换率。ARI 对编号置换不变，不是预测准确率；语义一致率不证明同名中心画像相同。
- 输出：汇总 JSON 包含全部 8 组、每区间 28 个两两比较及完整网格；逐日最小结果另存，保留日期、局部簇、稳定身份、标签、训练截止和模型版本。

当前基准组合在全历史产生 500 次完整标签切换，每 100 状态日 14.97 次，持续期中位数 2 日、P90 13 日；16 次切换位于重训边界，占全部切换 3.20%，占 53 个重训边界 30.19%。验证区间持续期中位数 2 日、P90 20.2 日，操作留出区间分别为 2 日、25.6 日。

**结论边界：** 当前网格下，随机种子单独变化的分区通常较接近，但训练窗口和重训间隔变化可产生明显差异，不能笼统称模型具有跨参数稳定性。该结果不是金融事件效果结论，也不自动说明某组参数更优。后续应结合状态画像、事件标注、覆盖和缺失影响研究差异来源；不得据本报告回看结果后删除较差组合。

## 3. 报告血缘与过期保护

真实产物位于 Git 忽略的 `server/data/benchmarks/`：

- `regime-stability.json`：页面和 API 读取的轻量汇总，绑定输入版本、特征版本、模型参数、特征内容摘要和源码 SHA-256。
- `regime-stability-daily.json`：8 组共 26,720 条逐日最小结果，SHA-256 为 `6d4fc99c3485528a4c1c80ac86a0b63a6024d962cfc2cd678fe3a757869f15e5`。

`GET /api/regimes/evaluation/stability` 由特征与状态服务拥有，主后端远程模式沿用既有代理。报告缺失返回 404；不可读取或与当前输入、特征、模型参数、评估版本不匹配返回 409，不静默展示旧结论。全资产范围的市场账号可读，受限资产账号仍返回 403。页面 `#/evaluation` 提供区间切换、完整网格、基准对照、两两 ARI 矩阵、JSON 导出和血缘摘要，不触发重新训练。

复跑命令（仓库根目录）：

```bash
PYTHONUTF8=1 conda run -n fintech python server/benchmarks/regime_stability.py
```

合成 E2E 后端使用独立资产生成自己的报告；其页面数值不替代上述真实行情结果。
