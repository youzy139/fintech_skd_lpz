# 演示视频录制脚本

目标：1920×1080、MP4、总时长 4 分 30 秒以内，留出低于 5 分钟的余量。使用已验收账号和真实赛题数据；隐藏密码、令牌、私有配置与开发者网络请求。已有 E2E 截图采用合成数据，只能明确标为测试证据。

| 时段 | 画面与操作 | 解说重点 |
| --- | --- | --- |
| 0:00–0:25 | 首页、打开市场工作台 | 研究多资产市场状态；当前是历史档案和事件时间回放 |
| 0:25–1:05 | 资产搜索、类别、范围切换及 CSV 导出 | 原始交易日历；价格与收益率单位区分；只导出可见范围 |
| 1:05–1:40 | 状态时间轴、热力图、特征走势 | 滚动训练截止早于观测日；标准化偏离不是因果 |
| 1:40–2:15 | 预警证据抽屉、规则版本、背景来源 | 数学状态 + 确定性规则；公开背景有可见时间边界 |
| 2:15–3:00 | 两日真实回放、运行 ID、逐日结果、耗时 | 事件时间与处理时间不同；不提前使用未来数据 |
| 3:00–3:35 | 数据中心、标签、原始字段、质量 | 1,046 文件与 1,556,492 逻辑记录；39/40 资产缺口公开 |
| 3:35–4:05 | 权限、审计与依赖监控 | 后端执行权限；缓存、共享限流、故障恢复边界 |
| 4:05–4:30 | 数据流图与发布清单 | 三服务与存储职责；公布实测与尚未达标项 |

录制前确认网站和 readiness 正常、回放范围确为两日、浏览器无个人信息。结束后逐段核对是否出现“实时行情”“高可用”“吞吐达标”等不实表述。验证视频分辨率、时长和字幕可读性；录制脚本不等于已交付 MP4。
