# MarketLens v0.4.3 测试版

日期：2026-11-14。用户明确要求“提交当前版本 更新计划书”，本批据此初步验收，整理提交、标签 `v0.4.3` 与推送。软件和部署工件声明为 `0.4.3`；该版本不代表竞赛正式交付。远端 CI 必须按本批准确提交核验，不沿用前版结果。

## 本批范围

- 账号可配置 `assets` 与 `sources` 两个 ID 白名单，`*` 表示全部。管理员固定全范围；用户更新会递增身份版本并撤销旧会话。创建账号默认全范围；旧版更新请求省略范围字段时保留原白名单，避免意外扩大权限。
- `auth_users.scopes` 以 SQLite 兼容迁移增加。历史账号没有范围字段时按 `assets=["*"]`、`sources=["*"]` 读取，不会因升级被意外锁出。
- REST 资产目录按资产范围过滤；资产序列和来源文件记录/质量明细按 ID 授权，越权明细以 404 隐藏资源是否存在。来源文件列表只返回白名单内项目。
- GraphQL 资产列表按资产范围过滤；来源汇总与目录全局摘要要求全来源范围。
- 受限来源账号不能访问全局目录摘要/版本指纹、来源概览/治理/标签统计、跨来源记录搜索、数据质量摘要或首页摘要。受限资产账号不能访问全市场状态、特征、预警、首页摘要、规则、回放和回放 WebSocket，因为这些结果基于全量行情输入；必须向账号显式授予 `assets=["*"]`。
- 缓存仍保存数据目录的权威全局查询结果。权限过滤在缓存读取之后执行，范围裁剪后的结果不写共享 Redis/本地目录缓存，因此请求顺序和缓存命中不能让账号读取其他范围的数据。

## 限制与待复验

受限账号目前不能获得按白名单资产重算的独立状态/特征/预警，也不能查看只针对授权来源重算的聚合治理报告。这里采用拒绝访问以避免用全量统计或模型输出绕过白名单，不代表已实现行级权限引擎或租户隔离。前端账号页允许填写逗号分隔的 ID；没有资源发现/批量选择控件，管理员需从现有列表复制准确 ID。跨独立数据服务、ClickHouse active、真实 Redis 负载和多用户浏览器流程仍待复验。
