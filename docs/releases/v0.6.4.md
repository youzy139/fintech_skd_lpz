# MarketLens v0.6.4 测试版

日期：2026-11-15。本批覆盖敏感性消融在固定 `5174 / 18000` 合成预览完成检查并开放网站验收，用户明确“继续开发”，按约定视为本批已初步验收并授权提交推送，整理版本 `v0.6.4`、提交与标签。该版本是模型输入覆盖研究里程碑，不是金融事件效果或竞赛正式交付。

## 本批范围

- 新增 `coverage-sensitivity-v1`，按当日有效收益资产数设置 `{1,5,10,20,31}` 五档门槛，应用到全部历史、开发、验证、操作留出区间。
- 只过滤既有状态日和三类预警，输出保留/排除数量与比例；不重训、不删除原始数据、不重新拼接状态、不制造跨缺口切换。
- 使用同一基准模型和报告固定规则参数，既有 8 组稳定性结果、评估 ID、模型卡、研究案例和回放结果不变。
- `#/evaluation` 在模型卡后新增覆盖消融表，随区间切换；旧报告缺少该字段时保持兼容。
- 报告血缘新增 `market_core/models/coverage.py` 源码摘要，基准脚本只读真实行情，不加载运行数据库。

## 真实结果与边界

真实基准为 3,340 个状态日和 1,102 条预警。≥31 门槛保留 **987 日，29.55%**；高波动 **43/242**、相关性异常 **50/360**、状态切换 **168/500**。

验证区间 ≥31 保留 474/1,096 日（43.25%），高波动 10/20、相关性异常 11/36、状态切换 64/138。操作留出 ≥31 保留 203/485 日（41.86%），高波动 6/11、相关性异常 1/4、状态切换 28/55。

这些数字说明预警数量必须结合资产覆盖解释。门槛只是敏感性分析，不是推荐生产配置；被过滤预警减少不等于误报减少。完整五档结果见 [覆盖消融专项](../v0.6.4-coverage-sensitivity.md)。

## 验证

- 后端 **263 项通过，分支统计总体覆盖率 80.15%**。
- 前端 **62 项通过**，TypeScript/Vite 生产构建通过。
- 固定端口真实 Chrome E2E 通过：五档消融、模型卡、研究案例、不同会话的两日回放及既有管理/移动流程；已复核表格截图。
- 真实报告已重新生成并保留版本血缘；未执行 Java、Kafka/Flink、容器或镜像专项，因为本批未修改这些实现。
- 8 处版本声明与 `git diff --check` 在提交前复核；发布后必须核对本版准确提交的远端 backend、frontend、browser-e2e、flink、containers 五项 CI，不能沿用旧版本结果。

## 限制与后续

真实事件标注、独立复核和 episode 回测仍未完成，不能由模型自动生成标注或金融结论。后续继续关闭持续吞吐、端到端、API、特征/识别、Redis 热特征、页面及故障性能等强制缺口，未达标项继续阻塞正式版。

固定验收预览继续使用 `5174 / 18000`，不得新增端口。后续每批仍须先打开网站验收，用户“继续开发”后才升版提交。
