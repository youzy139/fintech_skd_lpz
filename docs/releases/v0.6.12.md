# MarketLens v0.6.12 发布说明

发布日期：2026-11-16。用户在本批固定网站复核后明确要求“提交至git”，按项目约定视为初步验收并授权升版、提交、推送和创建 `v0.6.12` 标签。本版仍是测试版，不是 `v1.0.0` 正式竞赛交付。本版远端 backend、frontend、browser-e2e、flink、containers 五项任务须按准确提交的实际运行记录核验，不使用 v0.6.11 的成功记录替代。

## 本版范围

- 市场总览新增“复制研究链接”，以 `share=market-workspace-v1` 编码搜索、类别、观察列表、仅看收藏、选中资产和 60/250/500 日范围。
- 剪贴板不可用时展示只读链接输入框供手动复制；链接参数限制长度和数量，收藏去重，范围使用固定白名单。
- 打开链接后形成未保存分享视图，不自动调用 PUT，不覆盖接收者工作区；可一键恢复已保存内容并清除链接查询参数。
- 链接资产按接收者当前目录和权限裁剪，未知分享版本保留当前工作区并提示。
- 新增纯前端 `researchLinks.ts`，复用现有哈希路由和 v0.6.11 工作区；不新增 API、数据库表、服务、端口或模型事实源。
- 页面性能报告源码摘要纳入链接模块；基准保留前后端进程输出，便于诊断服务中途退出。

详细口径见 [可分享市场研究链接专项](../v0.6.12-research-links.md)。

**链接只恢复筛选，不冻结行情、模型、预警或历史时点结果。接收者仍须访问同一部署并通过登录和权限检查；`127.0.0.1` 链接仅适用于本机，不是公网分享。**

## 本地验证

- 后端完整回归 **302 项通过**，分支统计总体覆盖率 **80.81%**。随后新增链接源码摘要及基准日志，页面性能专项 **4 项通过**。
- 前端 **76 项通过**，TypeScript/Vite 生产构建通过。
- 固定 `5174/18000` 的真实 Chrome E2E 第二轮完整通过，覆盖“生成链接 → 直接打开 → 核实未覆盖 → 恢复已保存”及原有市场、评估、预警、系统、权限和真实两日回放流程。
- 第一轮 E2E 因“保存工作区”同时匹配“恢复已保存工作区”而选择器冲突，已改为精确名称并重跑，未改变业务断言。
- 真实只读行情预览中生成中证500、仅看收藏、60 日链接并直接打开，服务端保存内容保持一致；1440×1000 桌面和 390×844 移动 Chrome 已逐张复核，无页面脚本异常或根页面横向溢出。
- 八处版本声明同步为 `0.6.12`，锁文件只修改根包两处版本；提交前执行版本一致性和 `npm ci` 干跑校验。

## 限制与后续

- 链接不是服务端研究快照，没有命名分享、有效期、访问令牌、批注或独立权限管理；不冻结历史时点。
- 链接包含筛选文本和资产代码，接收者可见；公网、不同部署来源和多个真实账号之间未测。
- 页面测量仍限桌面本机、Vite 开发服务、单进程后端、合成三资产和小样本，不是生产、公网或全设备性能结论，也不是本批加速证据。
- API 客户端 `<50ms`、持续吞吐、端到端、资源与故障矩阵、真实金融事件标注和 episode 回测继续阻塞正式版。
- Java、Kafka/Flink 和容器应用实现未修改，本批未重新执行其专项；镜像标签更新不表示本地镜像已重建。
