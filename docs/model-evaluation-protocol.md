# 模型与预警效果评估协议

协议版本：`evaluation-v1-draft`，日期：2026-11-11。归属 `v0.3.5` 评估准备，完整报告计划在 `v0.6.0` 完成。本文固定拟采用的方法，尚无独立金融事件标注或准确率结果；人工标注与复核未完成前不能称为金标准。

## 1. 评估对象与隔离

分别验证时间正确性、状态稳定性、金融事件对照、预警效果和工程性能。中心匹配导致历史切换条数变化只能证明身份算法影响，不能直接当作误报减少或预测能力提高。模型不输出交易信号，不用收益率作为验收目标。

拟定区间：2017～2021 为开发区间，2022～2024 为验证区间，2025～2026-04-30 为最终留出区间。实际首个有效状态日与数据末日以载入结果为准，预热数据严格早于识别日。全部历史行情曾用于工程验证，当前留出区间属于后续效果评估的操作隔离，不宣称从未查看过。若已根据某区间效果调参，应披露并重新界定评估，不能继续称其为独立留出集。

先在开发区间固定参数、阈值、事件集规则及匹配窗口，保存配置摘要与来源；验证和留出区间不据结果筛选事件或调阈值。因设计缺陷修改协议时递增协议版本，保留旧结果并重新运行，不覆盖历史报告。

## 2. 事件标注与复核

由团队按可核查公开来源独立标注，不使用模型状态、预警日期或 LLM 自行判断充当真实事件。每条至少保存：

| 字段 | 含义 |
| --- | --- |
| event_id / category | 稳定事件标识和预先定义的事件类别 |
| published_at / timezone | 公开可见时间与时区，区分事实发生时间、统计期与公布时间 |
| window_start / window_end | 人工确认的研究窗口，说明为何有该区间 |
| source_url / source_title / retrieved_at | 可复核来源及取得时间 |
| annotator / reviewer / review_status | 标注、独立复核及争议状态，不补造人名 |
| asset_scope / relevance / uncertainty | 适用资产、相关性说明与不确定性 |

至少由标注者之外的成员复核；无法确定时间或存在争议的事件单列，不混入正式指标。按开发、验证与留出分区登记；冻结后才对照模型输出。当前只建立协议，没有生成虚假事件或人工复核记录。

## 3. 状态稳定性

先用 `centroid-alignment-v1` 对齐重训内的簇身份；跨参数运行的身份也需在共同历史区间对齐，不能直接比较 KMeans 编号。报告市场特征、训练窗口、重训间隔和随机种子的完整实验网格，不只列最好组合。

分别统计共同日期上的调整兰德指数、语义标签一致率、状态持续期、切换频率和重训边界切换占比；不同维度分开解释。同名簇仍是不同画像，不能通过合并标签人为提高一致率。报告样本覆盖、有效资产数量、缺失比例与不确定性；追加未来不改变历史由行为测试单独验证。

## 4. 预警回测与事件对照

三类规则分别评估，切换预警不是天然的危机预测。先为事件类别声明哪些规则可评估；不适用时显示“不可评估”，不能记为命中或漏报。事件对照也展示无预警事件和非事件日期，防止只挑案例。

拟采用事件公开日前后各 5 个状态日作为主要匹配窗口，并预登记 ±1、±10 个状态日的敏感性分析；这是待团队确认的研究口径，不是赛题指定阈值。提前量保留正负号，不能把事后触发计为提前预警。若窗口含事件后日期，指标名称应为“事件关联命中”，不能称为纯预测准确率。

同一规则连续触发合为一个 episode，以首日为时间；不同规则不混并。事件与 episode 按时间顺序作一对一匹配，冲突按绝对时间距离、再按较早日期和 event_id 确定；列出冲突与未匹配记录。报告 episode 精确率、事件召回率、每 100 状态日未匹配 episode 数、提前/滞后分布及原始逐日预警数，明确所有分子分母。

未匹配预警只有在事件集覆盖充分且类别适用时才能称误报；否则称“未关联”，并披露漏标可能。低事件数同时列置信区间和原始计数，不用小样本给出确定性优越结论。基线至少包含固定间隔切换提示和单指标历史分位规则；新文本或宏观输入另做消融，保留相同验证区间。

## 5. 可复现交付与当前待办

每轮保存协议/标注版本、数据与代码摘要、模型/身份算法/规则版本、训练截止、参数、逐日结果、事件匹配表及报告。性能报告单列冷/热与重训/非重训负载，不用统计效果替代工程性能。当前协议仍待团队确认并开始真实人工标注；这些工作持续列在 `v0.3.5` 未完成项，最终效果报告归 `v0.6.0`。
