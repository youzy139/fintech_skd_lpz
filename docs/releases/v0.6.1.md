# MarketLens v0.6.1 测试版

日期：2026-11-15。本版是已验收 `v0.6.0` 稳定性评估批次的发布修复，不新增未验收功能。初始标签推送后，远端 CI 的 `frontend` 与 `browser-e2e` 在 `npm ci` 失败，`backend` 和 `flink` 通过，`containers` 被跳过。旧标签不移动，本修订版统一软件与工件声明为 `0.6.1`。

## 修复范围

升版时过宽的批量替换误将 `web/package-lock.json` 中 `dom-accessibility-api` 的版本和下载地址从 `0.5.16` 改为不存在的 `0.6.06`。本版恢复该传递依赖的 `0.5.16` 版本与地址，仅保留项目自身根包版本 `0.6.1`。初始失败标签及原因保留在 [v0.6.0 发布说明](v0.6.0.md)，不得删除失败记录或移动旧标签。

模型稳定性评估、真实结果、API 和页面范围与 [v0.6.0 功能批次](v0.6.0.md) 相同。全历史两两 ARI 中位数 0.284、验证区间 0.566，仍不是预测准确率或金融效果证明。

## 验证结果

- 前端 **58 项通过**，TypeScript/Vite 生产构建通过。
- 固定端口真实 Chrome 完整 E2E 通过；随后复用 `5174 / 18000` 启动并打开评估页面，后端健康接口报告版本 `0.6.1`。
- `npm ci --dry-run --ignore-scripts` 成功解析锁文件；完整 `npm ci` 本地因工具权限拦截未执行，不能冒称完整安装通过。
- 8 处版本声明及 `git diff --check` 通过。
- 后端与算法未改变，功能批次已有后端 255 项、覆盖率 79.86% 的结果；本修订版未重新运行全量后端。

准确提交 `a63b20c94d5111304b469cac0f55e52a5a9b679e` 的远端 CI 已于 2026-11-15 实际核验为 **success**；backend、frontend、browser-e2e、flink、containers 五项均成功。运行地址：<https://github.com/youzy139/fintech_skd_lpz/actions/runs/43680682202>。本地未执行完整 `npm ci` 的限制仍如实保留，远端已执行并通过工作流中的安装与后续任务。
