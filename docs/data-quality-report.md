## 时间、字段与血缘

只用 `close` 计算价格收益；`yield` 是百分数。交易日期外连接，不前向填平不同市场的交易日。训练切片排除识别当日，回放按事件日期推进。

保留来源文件、记录序号、原始 payload 和事件日期。经济日历与公众号仅在前一状态日边界内作为背景证据；新闻、隐名指标、社交文本与研究摘要在时间语义未核实前不进入模型。标签用于检索，不代表情绪或因果结论。
