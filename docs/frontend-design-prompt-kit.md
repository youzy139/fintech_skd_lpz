# MarketLens 前端提示词包

> 一套按顺序执行的提示词。每条都可直接复制给模型，配合两张"卡片"使用。
> 基线：`v0.3.4` 工作区终端化前端（React 19 + 手写 `research.css` + ECharts 按需注册，无 CSS 框架、无路由库）。

## 0. 怎么用

1. 每次先贴 **卡片 A（公共约束）**，需要页面细节时再贴 **卡片 B（项目事实）**。
2. 再贴一条编号提示词，**一次只贴一条**。
3. 提示词 `03` 与 `06` 是"先出方案、等确认再改代码"的闸门，不要跳过确认。
4. 每条结束后跑验收：`cd web && npm test && npm run build`。

顺序（`02` 与 `03` 可并行，`04` 必须等两者完成）：

```
01 方向定调 → 02 IA 去重（首页问题）→ 03 设计系统重铸 → 04 首屏重排
→ 05 图表主题 → 06 文案去 AI 味 → 07 评审回路 → 08 一致性扫描
```

## 附：这套提示词的三条使用纪律

1. **一次一层**：token、结构、图表、文案分开做，每轮 diff ≤ 200 行，便于审阅与回退。
2. **先表后码**：`02` `04` `06` 都要求先出表格/清单，确认后再动文件——否则模型会"边想边改"，无法审计。
3. **用户验收优先**：`npm test` 与 `npm run build` 只证明没坏，不等于好看、不等于能讲清。演示前必须你自己按 1440 与 390 两个宽度点一遍。
